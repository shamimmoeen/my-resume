# Mainul Hassan — Resume

Personal resume built with HTML, SCSS, and Gulp. Includes a PDF export via Puppeteer.

**Live:** https://shamimmoeen.github.io/my-resume/

## Development

```bash
npm install
npm run dev       # dev server with live reload at http://localhost:3000
npm run build     # compile + minify CSS
npm run pdf       # regenerate Mainul-Hassan-Resume.pdf
```
